# @x402/near

NEAR mechanism scaffold for x402 v2.

This package is a preparation branch artifact for NEAR support in the v2 mechanism architecture.
It includes:

- Core NEAR types/constants
- DelegateAction Borsh encode/decode utilities
- `exact` client/server/facilitator scheme scaffolds
- Unit test fixtures for signed delegate actions

## Status

This package is intentionally not published yet and is kept on a prep branch until spec feedback is incorporated.
